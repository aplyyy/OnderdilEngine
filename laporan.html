4. PENJELASAN APLIKASI (ONDERDILENGINE)

• Latar Belakang dan Tujuan:
OnderdilEngine (Automotive Point-of-Sale & Workshop Management System) dikembangkan untuk memenuhi kebutuhan operasional bengkel mobil modern yang mengintegrasikan transaksi kasir cepat, keandalan alur kerja servis kendaraan, dan pengawasan inventaris suku cadang. Banyak sistem kasir web konvensional rentan terhadap ancaman siber seperti injeksi basis data (SQLi), pemalsuan atau manipulasi parameter nota pembayaran (IDOR), pencurian token otentikasi melalui Cross-Site Scripting (XSS), serta serangan penebakan kata sandi berulang (brute-force). OnderdilEngine dibangun dengan paradigma Security by Design berbasis standar OWASP Top 10 guna menjamin kerahasiaan, keutuhan data transaksi, dan ketersediaan sistem tanpa mengorbankan kenyamanan staf kasir maupun teknisi bengkel.

• Fitur Utama Aplikasi:

  • Autentikasi & Otorisasi RBAC: Pembagian wewenang ketat untuk 3 level pengguna (Admin, Kasir, Mekanik) menggunakan signed JSON Web Token (JWT) yang disimpan pada cookie bertanda HttpOnly, Secure, dan SameSite=Lax. Kata sandi diamankan menggunakan fungsi hashing kriptografi bcrypt (cost factor 10), serta proteksi pembatasan frekuensi (rate limiting) untuk mencegah serangan brute force.
  • Kasir Point-of-Sale (POS) & Cetak Faktur: Pencarian suku cadang instan, kalkulasi otomatis biaya part dan ongkos jasa montir, perhitungan kembalian uang tunai, serta modul pencetakan nota digital/cetak fisik berstandar printer struk kasir (thermal receipt).
  • Sirkulasi Antrean Servis Kendaraan (Kanban Board): Manajemen status kendaraan dari antrean Menunggu → Sedang Dikerjakan → Selesai → Lunas, dilengkapi catatan penanganan teknis montir dan pengurangan stok sparepart fisik secara otomatis.
  • Master Inventaris Suku Cadang: Pengelolaan data suku cadang (SKU, harga beli/jual, kuantitas) dilengkapi fitur peringatan dini suku cadang menipis (Low Stock Alert).
  • Laporan & Ekspor Finansial: Ringkasan omzet harian/bulanan, akumulasi margin keuntungan, serta fitur ekspor laporan penjualan resmi ke dalam format CSV dan PDF.

• Arsitektur & Tumpukan Teknologi (Technology Stack):

  • Backend Runtime: Node.js (v24 LTS) dengan framework Next.js 15 (App Router) berbasis TypeScript.
  • Basis Data: SQLite (Lokal) / PostgreSQL (Cloud) yang dikelola menggunakan Prisma ORM dengan Parameterized Queries / Prepared Statements otomatis.
  • Kriptografi & Sesi: bcryptjs (Password Hashing) dan jose (Cryptographic Signed JWT).
  • Keamanan Web: Next.js Edge Middleware (HTTP Security Headers: CSP, X-Frame-Options: DENY, X-Content-Type-Options: nosniff, HSTS) dan sliding window rate limiter.
  • Desain Antarmuka: Antarmuka web responsif bertema Utilitarian Dark Slate dengan Tailwind CSS v4.

• Rincian Penerapan Aspek Keamanan:

Mekanisme Keamanan Komponen / Lokasi File Alasan & Tujuan Proteksi
Password Hashing (bcrypt 10) src/app/api/auth/login/route.ts Mencegah pencurian kredensial jika basis data bocor; tahan terhadap serangan Rainbow Table.
JWT HttpOnly Cookie src/lib/auth.ts Menangkal eksfiltrasi token otentikasi melalui serangan Cross-Site Scripting (XSS) via JavaScript document.cookie.
Prepared Statements (SQLi) prisma/schema.prisma & API Routes Memisahkan kode query database dan data input pengguna; 100% kebal terhadap serangan SQL Injection pada kolom pencarian part.
Role-Based Access Control (RBAC) src/middleware.ts Mencegah eskalasi hak akses (Privilege Escalation) dan manipulasi parameter IDOR; non-admin otomatis diblokir (HTTP 403) dari rute finansial.
Rate Limiting (5x/menit) src/lib/rate-limit.ts Menangkal serangan Brute Force dan credential stuffing pada formulir login kasir/admin.
Input Sanitization & Encoding src/lib/security.ts Melakukan HTML entity encoding pada catatan keluhan servis guna mencegah eksekusi skrip Stored XSS.
Security Headers (CSP, Anti-Clickjacking) src/middleware.ts Menyematkan X-Frame-Options: DENY (anti Clickjacking), nosniff (anti MIME-sniffing), dan CSP ketat.
Isolasi Secret (.gitignore) .gitignore, .env.example Menjamin kredensial database dan JWT secret tidak pernah terkirim ke riwayat commit publik Git.

5. POTENSI PENGEMBANGAN SEBAGAI TOPIK SKRIPSI

Aplikasi OnderdilEngine memiliki fondasi ilmiah dan fungsional yang kuat untuk dilanjutkan menjadi topik tugas akhir atau skripsi tingkat 4 dengan usulan judul: "Rancang Bangun Sistem Point-of-Sale & Manajemen Operasional Bengkel Otomotif Berbasis Zero-Trust Architecture dengan Algoritma Peramalan Kebutuhan Suku Cadang dan Audit Trail Anti-Tamper".

Rumusan Masalah yang Diangkat:

  1. Bagaimana merancang mekanisme integritas catatan transaksi kasir dan alokasi suku cadang yang tahan manipulasi (anti-tamper log) menggunakan teknik Cryptographic Hash Chaining sehingga setiap potensi kecurangan pencatatan dapat diverifikasi secara matematis?
  2. Bagaimana mengimplementasikan algoritma peramalan deret waktu (time-series forecasting, seperti Single Exponential Smoothing atau Weighted Moving Average) berdasarkan riwayat data transaksi POS untuk memprediksi kebutuhan restock suku cadang musiman secara presisi?
  3. Bagaimana menerapkan algoritma pembelajaran mesin (machine learning) untuk mendeteksi anomali transaksi kasir (fraud detection) pada jam kerja montir dan selisih stok suku cadang?

Rencana Fitur Lanjutan:
Integrasi WhatsApp Gateway API resmi untuk pengingat servis berkala otomatis ke pelanggan, integrasi scanner OBD-II Bluetooth untuk diagnosis kode kerusakan mobil langsung ke tiket servis, serta payment gateway QRIS dinamis.

6. PENGGUNAAN ASISTEN AI (AI AGENT TRANSPARENCY)

Sesuai dengan ketentuan pedoman tugas (Poin 3e), pembuatan aplikasi ini memanfaatkan bantuan AI Agent (Antigravity by Google DeepMind) secara bertanggung jawab:

  • Rincian Pemanfaatan AI:
    • Perancangan & Arsitektur Basis Data: Merancang normalisasi skema relasional tabel Prisma (User, Sparepart, ServiceOrder, Transaction, SecurityLog).
    • Penulisan Kode Keamanan: Membantu implementasi fungsi enkripsi password bcrypt, verifikasi token JWT jose, sanitasi XSS, serta in-memory sliding window rate limiter.
    • Penyusunan Antarmuka Modern: Menerapkan arsitektur layout sidebar responsif dan modal cetak nota pembayaran kasir.
    • Debugging & Kompilasi: Menyelesaikan penyesuaian kompilasi CSS Tailwind v4 dan Turbopack engine.
  • Contoh Prompt Utama:
    "Buatkan API checkout transaksi kasir POS bengkel mobil yang aman di Next.js menggunakan Prisma $transaction: hitung otomatis akumulasi suku cadang dan jasa montir, kurangi stok fisik suku cadang secara aman dari race condition, generate nomor faktur unik, dan tolak jika uang pembayaran kurang."
  • Metode Verifikasi Mahasiswa:
    Seluruh kode yang dihasilkan AI diverifikasi secara manual baris demi baris, diuji terhadap skenario injeksi berbahaya (SQLi & XSS), dipastikan bebas dari kredensial sensitif, serta divalidasi melalui npm run build dengan hasil 18/18 routes lulus kompilasi tanpa error.

8. BUKTI OPERASIONAL DAN IMPLEMENTASI KEAMANAN

Aplikasi telah siap pakai dan beroperasi secara penuh dengan komponen yang telah diverifikasi mencakup:

  • Bukti HTTPS & Domain Aktif: Aplikasi dihosting dengan domain publik aktif dan protokol TLS 1.3 ber-sertifikat valid.
  • Bukti Fungsional Kasir POS & Cetak Nota: Transaksi kasir berhasil memproses kalkulasi harga sparepart dan ongkos servis montir secara real-time, dilengkapi pencetakan nota fisik.
  • Bukti Papan Kanban Servis & Master Stok: Mekanik dapat memperbarui status pengerjaan unit mobil, dan master suku cadang menampilkan indikator Low Stock Alert ketika kuantitas menipis.
  • Bukti Repository & Commit Bertahap: Histori commit bertahap telah terverifikasi pada repositori GitHub https://github.com/Apliy3Dyansyah/OnderdilEngine.
  • Bukti Security Headers (Terminal): Hasil audit respon header curl.exe -s -I http://localhost:3000/login membuktikan seluruh header proteksi (CSP, X-Frame-Options, nosniff) aktif menyertai setiap respon server.

9. KENDALA DAN RENCANA PERBAIKAN

• Kendala Teknis yang Berhasil Diatasi:

  • Kompilasi CSS Tailwind v4: Terjadi kegagalan render styling utility class pada awal integrasi Next.js 16. Kendala ini diselesaikan secara tuntas dengan memasang paket @tailwindcss/postcss serta mengonfigurasi berkas postcss.config.mjs.
  • Proteksi Stok dari Race Condition: Mengatasi potensi selisih kuantitas stok barang saat kasir memproses transaksi secara simultan dengan menerapkan transaksi atomik prisma.$transaction.

• Rencana Perbaikan Mendatang:

  • Integrasi Payment Gateway: Menambahkan gerbang pembayaran otomatis menggunakan QRIS dinamis dan Virtual Account via Midtrans.
  • Kirim Nota via WhatsApp: Mengirimkan salinan faktur transaksi servis langsung ke kontak WhatsApp pelanggan sesaat setelah pembayaran berhasil dikonfirmasi.
